OKKO on-line External Systems API

General

This is a API for connection clients ERPs to "OKKO online". API not support any operations that make changes Client profile in OKKO on-line system. In this API client should send HTTP request with data in JSON format and receive response in JSON format using UTF-8 encoding.

Authentication

This API using API keys for authorization. An API key is a key (token) that a client provides when making API calls. In our case it is sent as a request header.

Version changes

Added v2 API methods which schemas are aligned with the SSP API schemas.
Changed security schemes of v2 methods to API key.
Old methods are marked as deprecated.

get /v2/cards
receives a list of all cards or coupons depending on contract type (v2CardsGet)
ATTENTION! selector "card_status" can accepting value from "CSHT" dictionary - card status enum, or "CPNS" dictionary - coupon status enum, selector must contain value according to contract type. Maximum return 1000 object per request

Query parameters

contract_id (required)
Query Parameter — contract identifier
card_status (optional)
Query Parameter — card/coupon status according to metadata dictionary
unassigned (optional)
Query Parameter — if true - return only unassigned cards/coupons for any drivers
card_id (optional)
Query Parameter — card/coupon identifier
nominal (optional)
Query Parameter — nominal, applicable for coupons only
coupon_type (optional)
Query Parameter — type, applicable for coupons only, according to metadata dictionary
date_from (optional)
Query Parameter — start date of coupon activity, applicable for coupons only format: date
date_to (optional)
Query Parameter — end date of coupon activity, applicable for coupons only format: date
size (required)
Query Parameter — Quantity of rows to extract default: 20 format: int64
offset (required)
Query Parameter — Pagination offset (default 0) default: 0 format: int64

Return type

Cards

Example data

Content-Type: application/json
{
  "total" : 0,
  "cards" : [ "", "" ]
